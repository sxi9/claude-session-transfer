Scheduled sync

While the server runs, every interval it captures the sessions whose transcript changed since the last run into a dated bundle in the folder below. Point the folder at a shared drive, Dropzone, or a synced folder and the other PC can load from it.

Receiving from other PCs

Start this tool with python cst.py serve --host 0.0.0.0 on the receiving PC. The other PC pushes a bundle from its Load page using this PC's address and the peer token below. Pushed bundles land in the incoming folder.

Command line

python cst.py serve [--host 0.0.0.0] [--port 8765]   web UI (this)
python cst.py gui                                     tkinter window
python cst.py list [--account ID] [--all]
python cst.py capture --account ID --ids ID… --out bundle.zip [--memory] [--project] [--settings]
python cst.py load bundle.zip --account ID [--device ID] [--map OLD=NEW]… [--merge|--overwrite] [--dry-run]
python cst.py sync --account ID --dir FOLDER
python cst.py push bundle.zip --url http://PC:8765 --token TOKEN
python cst.py export --account ID --id ID --fmt md|html > file
